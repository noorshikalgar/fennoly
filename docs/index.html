Why Fennoly

Important papers are everywhere, except where you need them.

ID cards, insurance policies, tax returns, school reports, property papers, medical records. Every family has them, and today they live in photo galleries, chat threads, email attachments and old pen drives. When you need one, you search everywhere. When a phone is lost, they are lost with it.

Public clouds

Your family's most sensitive documents sit on someone else's servers, behind a monthly bill that keeps growing.

Do-everything suites

Self-hosted suites can do everything, which makes them heavy to run and confusing for parents and grandparents.

Archive tools

Document-archive tools are built for people who enjoy tagging and workflows, not for a family that just wants the ration card.

Fennoly does one thing well: it keeps a family's documents safe, organised and easy to reach. It runs on a small home server or an old PC, speaks your family's language, works beautifully on phones, and keeps your files as ordinary folders on disk, so you are never locked in.

Sharing

Share with family. Or with anyone, safely.

Give a family member access to a folder in two taps, as a viewer or an editor. For everyone else, create a public link: protect it with a password, let it expire, and decide whether people may download.

  • Visitors need no account; they see only what you shared
  • View and download counts on every link
  • One page shows everything you have shared
Uploads

Big files, bad Wi-Fi, no problem.

Fennoly splits large files into chunks, sends several at once, and checks each one. If the network drops, the phone switches to mobile data, or the page is closed, the upload picks up exactly where it stopped. Nothing is ever saved half-written.

  • Tested with a 5-minute outage on a slow line
  • Resumes after a reload or a server restart
  • Upload whole folders by dragging them in
Tools

Shrink that 3 MB photo before you send it.

Forms and portals often limit file sizes. Compress a photo or a PDF right where it is stored, see the new size before you commit, and keep the original if you like.

Backups

One copy is not a backup. Fennoly keeps another.

Choose where backups go, and Fennoly takes care of the rest every night: only changes are stored, old backups are thinned out, and a monthly check makes sure the copies can still be read. If something goes wrong, admins see a warning.

  • USB drive, NAS (SMB), SFTP, or S3 cloud such as Backblaze B2
  • Encrypted by default, with a printable recovery key
  • Restore any file or folder from any backup
  • Includes the database, so a new server can be rebuilt

Privacy

Your documents never leave your home.

Fennoly runs on a computer you own. There are no accounts with us, no analytics and no calls to anyone's cloud. This page itself loads nothing from other sites.

  • Files are plain folders on disk: take them anywhere
  • Passwords hashed with Argon2; repeated guesses are locked out
  • Uploaded files can never run code in the app
  • Tested like an attacker would: 138 checks, 0 holes
Install

Up and running in a few minutes.

You need a computer that stays on, like a home server, a NAS that runs Docker, a mini PC or an old laptop, with Docker installed.

Get Fennoly

git clone https://github.com/noorshikalgar/fennoly.git
cd fennoly

Set a database password and your time zone

Edit deploy/docker-compose.yml: change POSTGRES_PASSWORD in both places, and set TZ.

Start it

docker compose -f deploy/docker-compose.yml up -d --build

Open it and invite your family

Visit http://<your-server>:8686, create the first account (it becomes the admin), add family members, and set up a backup.

Questions

Good to know

Is it really free?

Yes. Fennoly is open source under the AGPL-3.0 licence. There is no paid version, no premium tier and no account to create with anyone.

What hardware do I need?

Anything that can run Docker and stay switched on: a mini PC, a NAS, a Raspberry Pi class machine or an old laptop. Disk space is what matters most.

Can I use it away from home?

Yes. Put it behind HTTPS (for example with Caddy) or use a private network such as Tailscale, and your family can reach it from anywhere, on any device.

What if I want to stop using Fennoly?

Your files are stored as ordinary folders with their real names. Copy the folder and you have everything, no export needed.

Are my files encrypted?

Backups are encrypted by default. Files on your own server are stored as they are, so they stay readable without Fennoly; use your operating system's disk encryption if you want them encrypted at rest too.

Is it ready?

Fennoly is young (version 0.1) and under active development. It is tested end to end, including a real backup and restore drill and a security test. As with any new software, set up backups and expect changes before 1.0. Coming next: Google Drive and OneDrive backups, full restore from the setup screen, and search inside scanned documents.
